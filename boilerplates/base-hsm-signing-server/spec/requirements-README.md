# Requirements

Requirement identifiers are stable and must be referenced in code-review notes and acceptance tests.

Families:

- `SZ-FUN-*` product behavior
- `SZ-SEC-*` security controls
- `SZ-HSM-*` HSM/DKEK
- `SZ-AUTH-*` human/workload identity
- `SZ-API-*` API/integrations
- `SZ-OS-*` appliance/OS/DCUI
- `SZ-AUD-*` audit
- `SZ-INS-*` install/setup/update
- `SZ-PWA-*` PWA/mobile approval
- `SZ-DOC-*` documentation

The machine-readable baseline is `requirements.yaml`; `traceability.csv` links requirements to specs, components and tests.
