# Public code-signing certificate providers

CA requirements and supported HSM attestation devices change. These guides intentionally link to official provider documentation and require the operator to confirm **Nitrokey HSM 2 / SmartCard-HSM acceptance and required attestation evidence with the CA before purchase/key generation**.

Current public code-signing ecosystems require hardware-protected private keys. Do not assume that possession of a CC-certified secure controller automatically means every CA will accept the complete token for subscriber-controlled issuance.
