# Nitrokey HSM 2 provider compatibility checklist

Before ordering a public code-signing certificate, record a provider case/ticket confirming whether the exact Nitrokey HSM 2 / SmartCard-HSM hardware and firmware is accepted, what certification evidence is required, and how externally verifiable key attestation must be supplied. Do not represent the appliance as CA-approved until that confirmation exists.

Track: provider, product (OV/EV), case ID, supported key algorithm/size, HSM model/firmware, attestation method, certificate download/import format, timestamp URL, renewal/rekey rule, revocation contact, date verified.
